NexaShop AI – AI-Powered E-Commerce Recommendation System

NexaShop AI is a modern AI-powered e-commerce platform that provides personalized product recommendations based on product similarity and user preferences. The application offers a complete online shopping experience with product browsing, category filtering, search, product details, cart management, wishlist functionality, user authentication, checkout, and intelligent recommendations.

The system is built using React + Vite for the frontend and FastAPI + SQLAlchemy + SQLite for the backend. It uses an AI-based recommendation system to analyze product information and suggest similar and relevant products to users.

Key Features:

🛍️ Product browsing and category-wise shopping
🤖 AI-powered similar product recommendations
🔍 Product search and filtering
❤️ Wishlist management
🛒 Shopping cart management
🔐 User login and signup
📦 Checkout and order flow
🖼️ Product images and detailed product pages
⚡ Fast and responsive modern UI
🔗 REST API powered backend

Tech Stack:

React • Vite • FastAPI • Python • SQLAlchemy • SQLite • Scikit-learn • REST API
